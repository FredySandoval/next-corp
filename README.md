# ▲ / NEXT-CORP

### A less opinionated **Turborepo** template for **enterprise-grade**, **production-ready** Next.js apps.

### Philosophy

next-corp is built around this core principles:

- **Seo** — Strong SEO for visibility, sharing, and long-term growth
- **Fast** — Quick to build, run, deploy, and iterate on
- **Less opinionated** — Made in such way you can build around it
- **Modern** — Latest stable features with healthy community support
- **Safe** — True End-to-end type safety and robust security postur

### stack

- Turborepo
- pnpm
- Next.js
- React
- TypeScript
- Prettier
- Node.js
